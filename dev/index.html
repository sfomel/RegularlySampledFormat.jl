RegularlySampledFormat

The RegularlySampledFormat package provides an interface for working with RSF files.

The RSF file format is used in the Madagascar open-source package for geophysical data analysis.

The format is documented in the Madagascar documentation.

Quick examples

Working with an existing RSF file

using RegularlySampledFormat

file = RSF("file.rsf");
data = file.data # a multi-dimensional Julia array

Creating an RSF file out of a multidimensional array

data = ones(Float32, 5, 2);
file = RSF(data, "file.rsf")

Open an RSF file for reading

inp = Input("file.rsf")
n1 = getint(inp,"n1")
T = gettype(inp)
trace = Array{T}(undef, n1)
dataread!(inp, trace)
fileclose(inp)

Open an RSF file for writing

out = Output("file.rsf")
putint!(out, "n1", 10)
setformat!(out,"native_int")
data = ones(Float32, 10)
datawrite(out, data)
fileclose(out)

RegularlySampledFormat.Datapath — Method
Datapath() -> String

Return the path to the data directory. The path is determined by checking the following sources in order of priority:
1. The environment variable `DATAPATH`.
2. A file named `.datapath` in the current working directory.
3. A file named `.datapath` in the user's home directory.
4. If none of the above sources provide a path, the function defaults to returning
the current working directory (`"./"`).
source
RegularlySampledFormat.Temp — Method
Temp() -> (String, IO)

Create a temporary data path. The temporary data path is determined by checking the following sources in order of priority:
1. The environment variable `TMPDATAPATH`.
2. The result of `Datapath()` function.

Returns a tuple containing the path to the temporary file and an IO object for writing to the file.

Extract an array of boolean parameters from the parameter table `par` for a given `key`.
